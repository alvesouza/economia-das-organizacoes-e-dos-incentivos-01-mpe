# Source exercises index

#map/exercises

Read first by `/exercise-plan`. One row per exercise; within a book, rows run by chapter, then
exercise number. **Verified = yes** means the number and the page were checked: for the
game-theory books, against the rendered PDF page when the practice lists were built (2026-10-13
for L01, 2026-10-25 for L02–L08); for the other books, read from the converted MD. MWG is a 2-up
scan, so pages not checked by a list come from two-page spreads (e.g. "474–475"): the exercise is on
one of the two pages. Difficulty letters (A/B/C) are MWG's own where the OCR kept them.

**Topics.** The game-theory tables (and the Ch. 7, 9 and 8 rows added to Cabral and Milgrom &
Roberts) use the T1–T19 names of [[Map/topics-index|topics-index]]. The other rows keep the topic
names of the superseded M&R plan (Moral hazard, Coordination through the market, ...), which
`topics-index` keeps under "Background and applications".

**Level and Used in.** Level comes from the list's tier (Foundations → foundational, Exam → exam,
Advanced → advanced); `extra` marks an exercise named only in a list's "Optional extras" paragraph
(no statement reproduced). "Used in" gives the list and item number: `pratica-lecture-03 #14` is
item 14 of `Listas/pratica-lecture-03.md`, `lista-reais #13` is item 13 of
`Listas/lista-reais-lectures-01-04.tex`, and `(sol.)` means a worked solution exists. "—" means no
list uses the exercise yet.

**The 50-exercise real list, Lectures 1–5 (2026-11-06)** is not repeated row by row here: its
items (exercise ID, combined and per-lecture number, difficulty 1–5) are in
`Listas/lista-reais-lectures-01-05/order.md`, and every one of the 50 has a detailed solution in
`Listas/lista-reais-lectures-01-05-solutions.pdf` (per lecture: `lista-reais-lecture-0N-solutions.pdf`).
