## harsanyi

Q: In Harsanyi's ex ante game each player picks a whole type-contingent plan before learning his type, to maximize his prior expected payoff. Why are its Nash equilibria the profiles in which every type, of positive probability, best-responds given its own interim belief?
- Because players in fact choose their plans before Nature moves, so the interim conditions are only a convenient way of checking an ex ante choice
- Because the common prior makes every type's interim belief equal to the prior, so maximizing the prior expected payoff maximizes every interim payoff
- Because the prior expected payoff is a probability-weighted sum of the types' interim payoffs, and each type's action enters only its own term of that sum
- Because a Nash equilibrium needs correct beliefs about strategies, and in a Bayesian game those beliefs are correct only if each type plays a dominant action
<!-- YW5zOjI= -->
> Right: player $i$'s ex ante payoff is $\sum_{\theta_i}\Pr(\theta_i)\,E[u_i \mid \theta_i]$, and the action of type $\theta_i$ appears only in the term for $\theta_i$. Maximizing the sum over plans is therefore the same as maximizing each term separately, for every type with $\Pr(\theta_i) > 0$. This is Tadelis's "meta-player" argument and MWG's Proposition 8.E.1. Wrong: the equivalence is a mathematical fact, not a claim about timing (players do learn their types first); interim beliefs equal the prior only with independent types; and nothing requires dominant actions.
> Ref: Tadelis (2013), Ch. 12 opening, the meta-player (p. 245) and Def. 12.4 (p. 251); Gibbons (1992), §3.1.C (p. 151); MWG (1995), §8.E, Prop. 8.E.1 (p. 256)

Q: Player 1's type is $a$ or $b$, and player 2's is $c$ or $d$. Each type of player 1 believes player 2 is of type $c$ with probability $1/2$. Player 2's type $c$ believes player 1 is of type $a$ with probability $3/4$, and type $d$ believes it with probability $1/4$. Can these interim beliefs come from a common prior?
- Yes, from the uniform prior putting $1/4$ on each type profile, since every belief listed is a conditional of that distribution, computed by Bayes' rule
- Yes, from a prior with $\pi(a,c) = \pi(b,d) = 3/8$, since the extra weight on matched pairs produces exactly the beliefs of player 2's two types
- Yes, since any set of interim beliefs on finite type spaces comes from some prior, and the common prior assumption only fixes which one is used
- No: player 1's beliefs force $\pi(a,c) = \pi(a,d)$ and $\pi(b,c) = \pi(b,d)$, which give both types of player 2 the same belief about player 1
<!-- YW5zOjM= -->
> Right: $\pi(c \mid a) = 1/2$ means $\pi(a,c) = \pi(a,d)$, and likewise for $b$. Then $\pi(a \mid c) = \pi(a,c)/(\pi(a,c)+\pi(b,c))$ equals $\pi(a \mid d) = \pi(a,d)/(\pi(a,d)+\pi(b,d))$, so player 2's two types must hold the same belief; $3/4 \ne 1/4$, so no common prior exists. Wrong: the uniform prior gives player 2 the belief $1/2$; the prior with $3/8$ on matched pairs gives player 1's type $a$ the belief $\pi(c \mid a) = 3/4$, not $1/2$; and the example itself shows that not every belief system is generated by a common prior.
> Ref: Tadelis (2013), §12.1.2, Def. 12.2 and the worked prior (pp. 247–249); Gibbons (1992), §3.1.B (p. 149)

Q: Player 2's payoffs are known to everyone, but player 1 does not know whether player 2 has been told player 1's cost, which matters only for player 1's payoff. How should this be modelled as a Bayesian game?
- Give player 2 types that differ in what he has learned, with identical payoffs, since a type encodes a player's information and beliefs, not only his payoffs
- Give player 2 a single type, since types describe payoffs only, and player 2's payoffs are the same whether or not he has been told player 1's cost
- Give player 1 more types, one for each thing player 2 might know, since only the player who is uncertain can have more than one type in a Bayesian game
- Drop the common prior, since uncertainty about what another player knows cannot be described by Nature's draw from a commonly known distribution
<!-- YW5zOjA= -->
> Right: a type is everything a player privately knows that matters for play, payoffs or information; a told player 2 can condition his action on player 1's cost and an untold one cannot, so they must be different types even with the same payoff function. Harsanyi's device, made precise by Mertens and Zamir, uses rich type spaces to capture beliefs about beliefs. Wrong: a single type would ignore that player 2's action may depend on what he knows; any player whose information is private can have several types; and Nature can draw "told or not told" from a commonly known prior.
> Ref: Tadelis (2013), §12.1.1, the definition of types and the Remark on belief hierarchies (pp. 246–247)

Q: Write a static Bayesian game in extensive form: Nature first draws the types, then each player moves knowing only his own type. Why does subgame perfection add nothing to Bayesian Nash equilibrium there?
- Because each player knows his own type, so every node after Nature's move starts a subgame, and in a static game a Nash equilibrium is already optimal in each of them
- Because each information set pools nodes that differ in the others' types, so no proper subgame starts after Nature's move; the only subgame is the game itself
- Because Nature is not a player, so its move cannot be followed by a subgame, and subgame perfection applies only to subgames that begin with a player's decision
- Because Bayesian Nash equilibrium already imposes Bayes' rule at every information set, which is a stronger requirement than optimality in every subgame
<!-- YW5zOjE= -->
> Right: a subgame must start at a singleton information set and contain whole information sets; a player who does not know the others' types has information sets that cut across Nature's branches, so no proper subgame exists, and subgame perfection reduces to Nash equilibrium of the whole game. This is why dynamic games of incomplete information need perfect Bayesian equilibrium. Wrong: knowing one's own type does not make one's node a singleton information set; subgames can follow a move by Nature when the following node is a singleton; and Bayesian Nash equilibrium uses Bayes' rule only on the prior, not at unreached information sets.
> Ref: Tadelis (2013), §12.1.3, types as information sets (p. 250) and §15.1 (p. 306); Gibbons (1992), §4.1 (pp. 176–177)

## bne

Q: In a Bayesian game, player 2 has a type $\theta'$ to which the common prior assigns probability zero. Compare a Nash equilibrium of Harsanyi's ex ante game with a profile in which every type best-responds given its interim belief. Which statement is correct?
- An ex ante equilibrium may give $\theta'$ any action, since its play moves no prior expected payoff, so the equivalence holds only for positive-probability types
- The two always coincide, since the ex ante payoff is the sum of the types' interim payoffs, so a type that fails to best-respond lowers its player's ex ante payoff
- The type $\theta'$ must play a dominant action in both, since a type that is never drawn has no belief about the others and so can use only dominance
- Neither concept is defined, since a type of zero prior probability makes the posterior beliefs of the other player's types undefined by Bayes' rule
<!-- YW5zOjA= -->
> Right: the ex ante payoff weights each type's interim payoff by its prior probability, so a zero-probability type's action has zero weight and can be anything in an ex ante Nash equilibrium. MWG's Proposition 8.E.1 states the equivalence for every type that occurs with positive probability. Wrong: the sum argument breaks down precisely at zero weights; nothing forces dominance; and the other player's beliefs condition on his own types, which have positive probability, so they are well defined.
> Ref: MWG (1995), §8.E, Prop. 8.E.1 (p. 256); Tadelis (2013), Def. 12.4 (p. 251)

Q: In Tadelis's chicken game each driver swerves (payoff $0$) or drives; driving pays $8$ against a swerver and $4 - k_i$ against a driver, where the accident cost $k_i$ is $0$ or $16$ with probability $1/2$ each, independent and private. The unique pure Bayesian Nash equilibrium has the $k_i = 0$ type drive and the $k_i = 16$ type swerve. What happens ex post?
- No type ever regrets its action once types are revealed, since a Bayesian Nash equilibrium is a Nash equilibrium of the game played in each realized state
- Two $k_i = 0$ types who meet regret driving, since each gets $4 - 0 = 4$, less than the $8$ each would get if the other had swerved instead
- Two $k_i = 16$ types who meet both swerve and get $0$, though each would get $8$ by driving: the equilibrium is optimal interim, not ex post
- Two $k_i = 16$ types who meet both swerve, which is a Nash equilibrium of the realized complete-information game, so neither regrets the outcome
<!-- YW5zOjI= -->
> Right: against a swerver, driving pays $8 > 0$, so each harsh-parent driver who meets another harsh one regrets swerving; he swerved because, interim, the opponent drives with probability $1/2$ and driving would then cost $4 - 16 = -12$, giving an expected $\tfrac12(8) + \tfrac12(-12) = -2 < 0$. A Bayesian Nash equilibrium is optimal against beliefs, not against the realized types. Wrong: the first option confuses BNE with ex post equilibrium; two lenient types get $4$ by driving against $0$ by swerving, so they do not regret their own choice (regret compares one's own actions, not the opponent's); and both swerving is not a Nash equilibrium of the realized harsh–harsh game, since driving against a swerver pays $8$.
> Ref: Tadelis (2013), §12.2.1, chicken with $R = 8$, $H = 16$, $L = 0$ (pp. 252–255)
> Similar: Tadelis (2013), Exercise 12.1, p. 266

Q: A modeller solves a two-player game of incomplete information by finding, for each profile of types, the Nash equilibrium of the complete-information game with those types, and calls the collection a Bayesian Nash equilibrium. What is wrong with this?
- Nothing, provided types are independent, since then each player's belief is the prior, and the state-by-state equilibria average to a best response
- A player's action then depends on the other's type, which he does not know; a strategy must map his own type alone to an action, chosen against his belief
- Nothing, provided each complete-information game has a unique Nash equilibrium, since uniqueness makes the collection a well-defined type-contingent plan
- The collection ignores the common prior, which must weight the states, though each state's equilibrium action is still the right action for each type
<!-- YW5zOjE= -->
> Right: a strategy is a map $s_i : \Theta_i \to A_i$; a state-by-state solution typically has player $i$'s action vary with $\theta_j$, which $i$ cannot condition on, so it is not even a strategy profile of the Bayesian game. Even where it happens to depend on own types only, each type must best-respond to the distribution of the other's actions, not to one realized action. Wrong: independence does not let a player see the other's type; uniqueness of each state's equilibrium does not remove the dependence on the other's type; and the state's equilibrium action is in general not a best response once the other's type is uncertain.
> Ref: Tadelis (2013), §12.1.3, Defs. 12.3–12.4 (pp. 249–251); Gibbons (1992), §3.1.C (pp. 149–151)

Q: With private values each player's payoff depends on the actions and on his own type only; with common values it may depend on the others' types too. If player 1 learned player 2's type before acting, how would that information matter in each case?
- In both cases only through player 2's predicted action, since a type matters to the others only through what it makes its owner do in equilibrium
- Under private values it changes what each outcome is worth to player 1, while under common values it changes only his forecast of player 2's action
- In neither case, since a Bayesian Nash equilibrium already conditions each type's action on the expected type of the opponent through the common prior
- Under private values only through player 2's predicted action; under common values also through what each outcome is worth to him, where curses arise
<!-- YW5zOjM= -->
> Right: with private values, $u_1(a;\theta_1)$ does not involve $\theta_2$, so learning $\theta_2$ helps player 1 only to predict $s_2(\theta_2)$. With common values, $u_1(a;\theta_1,\theta_2)$ changes with $\theta_2$, so the information changes the value of outcomes themselves; this is why adverse selection and the winner's curse need common values. Wrong: the first option holds only for private values; the second swaps the two cases; and learning the realized type is more than the expectation the prior provides.
> Ref: Tadelis (2013), §12.1.1, private values and common values (p. 247); Gibbons (1992), §3.1.B (p. 149)

Q: In a Bayesian Nash equilibrium, type $\theta_H$ of player 1 earns an expected payoff of $-1$ and type $\theta_L$ earns $+3$, each with prior probability $1/2$, so player 1's ex ante expected payoff is $+1$. If player 1 could opt out for a payoff of $0$, what would decide whether he takes part?
- Only the ex ante payoff, since a player commits to his type-contingent plan before Nature moves, and $+1 > 0$ makes taking part worth it for both types
- The timing: deciding before learning his type he takes part, but deciding after it type $\theta_H$ opts out, which may change the others' best replies too
- Only the interim payoffs, since a Bayesian Nash equilibrium is defined type by type, so the ex ante payoff of $+1$ has no meaning in a Bayesian game
- Neither, since opting out is just another action, and in a Bayesian Nash equilibrium a type with a negative payoff would already have switched to it
<!-- YW5zOjE= -->
> Right: before learning his type, player 1 compares $+1$ with $0$ and takes part; after learning it, type $\theta_H$ compares $-1$ with $0$ and leaves. Once a type leaves, the others' beliefs about who takes part change, so their equilibrium behaviour can change too, the mechanism behind adverse selection. Wrong: players learn their types before acting, and the ex ante plan is a device for computing equilibria, not a commitment; the ex ante payoff is well defined, by the prior; and the opt-out option is not in the original game, so its equilibrium cannot have used it.
> Ref: Tadelis (2013), §12.1.3, the plan read "as if" chosen before learning one's type (p. 249); Tadelis (2013), §12.3, inefficient trade and adverse selection (pp. 258–260, background for T16)

Q: Why does every finite Bayesian game, with finitely many players, actions and types, have a Bayesian Nash equilibrium, possibly in mixed strategies?
- Because a Bayesian Nash equilibrium is a Nash equilibrium of the Harsanyi game, which is a finite game, so Nash's existence theorem applies to it directly
- Because each type faces a single-agent decision problem against the prior, which always has a solution, so every type has a best action whatever the others do
- Because uncertainty about types acts like a mixed strategy of the opponent, which smooths every best response into a function with a pure-strategy fixed point
- Because the common prior ensures that some type of each player has a dominant action, and iterated elimination from those types leaves at least one profile
<!-- YW5zOjA= -->
> Right: with $|A_i|$ actions and $|\Theta_i|$ types, player $i$ has $|A_i|^{|\Theta_i|}$ pure type-contingent plans, so the Harsanyi game is an ordinary finite game; it has a mixed Nash equilibrium, and that equilibrium is a Bayesian Nash equilibrium. Wrong: every type having a best reply to each fixed profile does not give mutual consistency, which needs a fixed point; type uncertainty does not guarantee pure equilibria (purification is a separate result for perturbed payoffs); and nothing guarantees dominant actions.
> Ref: Gibbons (1992), §3.1.C (pp. 151–152); Tadelis (2013), §12.1.3 (p. 251)
