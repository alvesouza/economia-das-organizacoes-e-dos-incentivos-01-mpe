# Lecture 4 — Multistage games and bargaining · Map of the notes

> **Estimated unit.** Built on 2026-10-16 from the study guide before the lecture. Reconcile with the slides when Aula/Lecture04.pdf arrives (/notes 04 --reconcile).

> **One claim.** **Later play can discipline earlier play, but only through equilibria.** In a
> multistage game a threat is credible only if it is a Nash equilibrium of the stage where it is
> carried out, so behaviour that is not a stage-1 equilibrium needs **a carrot and a stick in a
> later stage and enough patience** to make the gap bite. **Bargaining is the same logic run
> backwards from a deadline:** each proposer offers the responder exactly what rejecting is worth,
> so agreement is immediate and the split is set by the threat that is never carried out. **Without
> a deadline, stationarity replaces the last period:** the proposer gets $\frac{1}{1+\delta}$, and
> **patience is bargaining power**.

## The one result to hold

$$\boxed{\;x^*=\frac{1-\delta_2}{1-\delta_1\delta_2}\ \xrightarrow{\ \delta_1=\delta_2=\delta\ }\ \frac{1}{1+\delta}\ \xrightarrow{\ \delta\to1\ }\ \frac12\;}$$

> **The proposer's share is set by what the responder could get by waiting.** The same sentence
> gives the finite game's induction, the infinite game's stationarity, the legislative proposer's
> price per partner, and, in Part I, the carrot-and-stick threshold $\delta\ge g/(c-s)$.

## Numbers and cases to have memorized

| Case | Value | Meaning |
|---|---|---|
| Prisoner-Revenge, $(M,m)$ | $\delta\ge\frac13$ | gain 1 against a stick worth 3 |
| Prisoner-Revenge, $(F,m)$ | $\delta\ge\frac23$ | gain 2 against the same stick |
| Ultimatum SPE | $(1,0)$ | Nash allows any split |
| Two rounds | $(1-\delta,\ \delta)$ | the last word is worth $\delta$ |
| Finite, $\delta=0.6$ | $1,\ 0.4,\ 0.76,\ 0.544,\dots\to0.625$ | zig-zag to $\frac1{1+\delta}$ |
| Rubinstein | $\frac1{1+\delta}$; $\frac{1-\delta_2}{1-\delta_1\delta_2}$ | first-mover edge only |
| Tariffs | $t^*=\frac{a-c}3$ | dominant, and jointly worse than free trade |
| Legislative, $N=3$ | closed $1-\frac\delta3$; open $\frac1{1+2\delta}$; switch at $\sqrt3-1$ | protocol is power |
