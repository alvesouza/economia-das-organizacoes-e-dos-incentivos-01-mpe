# Study notes · index

One folder per lecture, built with `/notes` (spec: `.claude/commands/notes.md`). Each unit
opens at its map, then reads in order: one note per section (layers **U** intuition, **C**
examinable, **G** formal/MWG), then `-formulas`, `-pitfalls` (with an original True/False
self-test) and `-python`. Figures: `python Notas/LNN/figures/make_figures.py`. Companions are
local HTML pages, opened by double-click; each unit's `companions/check_companions.py`
verifies them against Python.

**Estimated** units were written from `Map/study-guide.md` and the books before the lecture.
When the slides arrive, run `/notes NN --reconcile`.
