## Where the estimate was wrong

| Estimate | Reality | Consequence |
|---|---|---|
| 16 sessions | 8 content lectures | about half the teaching time; one lecture per week |
| M&R organization topics | game-theory solution concepts | M&R becomes application background, not the spine |
| Bargaining = Coase + private information, alternating offers as a supplement | L4 = multistage games and bargaining | Rubinstein (Aula 2 notes §5.2, list 01–02 block 3) is now core |
| Adverse selection ×3 sessions | L7 (with Bayesian games and auctions) + L8 (signaling, PBE) | same content, as games of incomplete information |
| Moral hazard ×4 sessions | not on the schedule | M&R Ch. 6–7 only through relational contracts (L6) |
| Efficiency, coordination, NEPKE, Sears, S&L | not on the schedule | dropped from the core |
| — | static games, SPE, repeated games, auctions, PBE | new core material, no project coverage yet |
| no exam slot | final exam Dec 8 (55%) | the exam is the main target |
| — | short paper with a model (35%) | needs its own track: topic, model, presentation Dec 1 |

Timing: L4 (Tue Nov 3), L5 (Fri Nov 6) and L6 (Tue Nov 10) fall within eight days — the
heaviest stretch; prepare repeated games before Nov 3.
