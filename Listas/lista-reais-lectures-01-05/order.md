# Item order: lista-reais-lectures-01-05 (50 items, 10 per lecture)

The final order of the real-exercise list for Lectures 1–5. `blockN.tex` follows it item by item.
Every block runs in strictly rising difficulty, with items 1–3 foundations, 4–8 exam level and
9–10 advanced. The last item of each block is the hardest.

Columns:
- **L#**: number in the per-lecture list (`lista-reais-lecture-0N.pdf`).
- **All#**: number in the combined list (`lista-reais-lectures-01-05.pdf`).
- **Slug**: name to use for solution files.
- **Diff.**: difficulty, from 1 (apply a definition) to 5 (graduate level).
- **Status**:
  - `01-04` = reused unchanged from `lista-reais-lectures-01-04.tex`. Its solution is
    `lista-reais-lectures-01-04-solutions/itemNN.tex`, with NN given in the next column.
  - `new-30` = added in the 30-item version (2026-11-06), not in the 01-04 list.
  - `new-50` = added in this 50-item version.
- **01-04 #**: the item's number in the 01-04 list, for `01-04` items only.

Items that need a new solution are all `new-30` and `new-50` items (31 in all).
