The Complementarity Multiplier

"Incentives and delegated authority are complements: each makes the other more valuable" (M&R, p. 17). Give the field more valuable local information and the firm delegates more; more delegation makes incentive pay worth more; stronger incentives make delegation worth more again. The staircase is those rounds. The multiplier is where they end.

Environment

How much better decisions get when the people on the spot make them. Raises the return to delegating.

How well performance can be measured and paid for. Raises the return to incentive pay.

Structure

How much each choice raises the marginal return of the other. Zero: independent. Negative: substitutes.

How fast the gain from each choice runs out. A maximum exists only while c is larger than |b|.

The answer

The model

π(x, y) = t·x + s·y + b·x·y − (c/2)·x² − (c/2)·y²,   x = delegated authority, y = incentive intensity (both measured from a baseline)
First-order conditions: t + b·y = c·x,  s + b·x = c·y  ⇒  x* = (c·t + b·s) / (c² − b²),  y* = (c·s + b·t) / (c² − b²),  maximum iff c > |b|
∂x*/∂t = c / (c² − b²) = (1/c) · 1 / (1 − (b/c)²) = (1/c)·(1 + (b/c)² + (b/c)⁴ + …),   ∂y*/∂t = b / (c² − b²),   ∂²π/∂x∂y = b
